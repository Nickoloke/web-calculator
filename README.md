# TypeScript Web Calculator

# Highlights

* Normal TypeScript HTML and CSS
* Type-safe math operations error handling
* Responsive UI with clear indicators.

# Overview

This is a browser based calculator built entirely with TypeScript, HTML, and CSS. I built this project as a starter typescript project in order to familiarise myself with the corresponding languages.
